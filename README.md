# Lotofácil Engrossando o Talo V1

Projeto Android independente para GitHub/APK.

Motor transposto do código PyDroid:
- Lotofácil 01 a 25;
- usuário escolhe 8, 9 ou 10 repetidas do último concurso;
- gera todas as combinações das repetidas;
- gera todas as combinações do espelho/falhas;
- mede talo em movimento para cima;
- usa série 18, série 6, slope 18, slope 6, crescimento, persistência, subidas e movimento final;
- cruza repetidas + espelho;
- aplica estrutura histórica;
- aplica P01 a P15;
- PDF com verde = jogo e vermelho = falha.
